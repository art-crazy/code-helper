# 🤝 Руководство по вкладу в проект

Спасибо за интерес к развитию Code Helper! Мы приветствуем любой вклад в проект.

## 🚀 Как начать

1. **Fork репозиторий**
2. **Клонируйте ваш fork**
   ```bash
   git clone https://github.com/your-username/code-helper.git
   cd code-helper
   ```
3. **Установите зависимости**
   ```bash
   npm install
   ```
4. **Создайте ветку для вашей фичи**
   ```bash
   git checkout -b feature/amazing-feature
   ```

## 💻 Разработка

### Структура проекта

- `src/components/` - React компоненты
- `src/services/` - Сервисы (API, storage)
- `src/hooks/` - React hooks
- `src/utils/` - Утилиты
- `src/content_scripts/` - Content scripts
- `src/background/` - Background service worker

### Стиль кода

- Используйте TypeScript для новых файлов
- Следуйте ESLint правилам
- Добавляйте JSDoc комментарии
- Используйте осмысленные имена переменных

### Запуск в dev режиме

```bash
npm run dev
```

## ✅ Чеклист перед commit

- [ ] Код работает без ошибок
- [ ] Добавлены комментарии
- [ ] Обновлена документация (если нужно)
- [ ] Проверено в Chrome
- [ ] Следует стилю проекта

## 📝 Commit сообщения

Используйте conventional commits:

```
feat: добавить новую фичу
fix: исправить баг
docs: обновить документацию
style: форматирование кода
refactor: рефакторинг
test: добавить тесты
chore: обновление зависимостей
```

## 🔀 Pull Request

1. Убедитесь, что ваш код работает
2. Обновите документацию
3. Создайте Pull Request с описанием изменений
4. Дождитесь ревью

## 🐛 Сообщение об ошибках

Используйте GitHub Issues с:
- Описанием проблемы
- Шагами воспроизведения
- Ожидаемым поведением
- Скриншотами (если возможно)
