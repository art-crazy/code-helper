# 📥 Инструкция по установке Code Helper

## Быстрая установка для пользователей

### Шаг 1: Скачайте расширение

Скачайте последнюю версию из [Releases](../../releases) или соберите из исходников (см. ниже).

### Шаг 2: Установите в Chrome

1. Откройте Chrome и перейдите на `chrome://extensions/`
2. Включите **"Режим разработчика"** в правом верхнем углу
3. Нажмите **"Загрузить распакованное расширение"**
4. Выберите папку `dist` (или распакованную папку релиза)
5. Расширение установлено! 🎉

### Шаг 3: Получите Gemini API ключ

1. Перейдите на [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key)
2. Войдите в аккаунт Google
3. Нажмите **"Get API Key"**
4. Создайте новый проект (если требуется)
5. Скопируйте ваш API ключ

### Шаг 4: Настройте расширение

1. Кликните на иконку расширения в панели Chrome
2. Вставьте ваш API ключ в поле
3. Нажмите **"Сохранить ключ"**
4. Готово к использованию! ✅

## Сборка из исходников (для разработчиков)

### Требования

- Node.js 18 или выше
- npm 9 или выше
- Git

### Команды установки

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/code-helper-chrome-extension.git
cd code-helper-chrome-extension

# 2. Установите зависимости
npm install

# 3. Соберите расширение
npm run build

# 4. Папка dist готова к загрузке в Chrome
```

### Режим разработки

```bash
# Запустите в режиме разработки с hot reload
npm run dev

# Или используйте watch mode для автоматической пересборки
npm run watch
```

## Проверка установки

После установки проверьте, что расширение работает:

1. Откройте любую страницу с кодом (например, [LeetCode](https://leetcode.com))
2. Кликните на иконку расширения
3. Расширение должно обнаружить код на странице
4. Попробуйте проанализировать код

## Устранение проблем

### Расширение не обнаруживает код

- Обновите страницу после установки расширения
- Убедитесь, что на странице действительно есть блоки `<code>` или `<pre>`
- Попробуйте выделить код вручную

### Ошибка API ключа

- Проверьте, что ключ скопирован полностью
- Убедитесь, что ключ активен в Google Cloud Console
- Проверьте квоты API

### Расширение не загружается

- Убедитесь, что папка `dist` содержит все файлы
- Проверьте консоль Chrome на наличие ошибок
- Попробуйте пересобрать проект: `npm run build`

### Проблемы с зависимостями

```bash
# Очистите кэш и переустановите
rm -rf node_modules package-lock.json
npm install
```

## Обновление расширения

### Для пользователей

1. Скачайте новую версию
2. Удалите старую версию в `chrome://extensions/`
3. Загрузите новую версию

### Для разработчиков

```bash
git pull origin main
npm install
npm run build
# Перезагрузите расширение в Chrome (кнопка обновить)
```

## Удаление расширения

1. Откройте `chrome://extensions/`
2. Найдите "Code Helper"
3. Нажмите **"Удалить"**
4. API ключ также будет удален из Chrome Storage

## Безопасность API ключа

⚠️ **Важно**: Ваш API ключ хранится локально в Chrome и никогда не передается третьим лицам.

- Ключ зашифрован Chrome через `chrome.storage.sync`
- Используется только для прямых запросов к Google Gemini API
- Не храните ключ в общедоступных местах
- Не коммитьте ключ в Git
